argument-hint: "[対象spec番号 (省略時は最新)]"
---

対象の plan.md を、実行順のタスクチェックリストに分解してください。

対象: $ARGUMENTS (省略時は `specs/` 内で最も番号が大きいディレクトリ)

手順:

1. 対象の `specs/<NNN>-<slug>/plan.md` を読む。
2. `specs/_template/tasks.md` を `specs/<NNN>-<slug>/tasks.md` としてコピーする。
3. 以下の順序でタスクを列挙する (各タスクは1〜数ファイル程度の粒度に分割し、
   対応する要件ID/設計項目を明記する):
   モデル → マイグレーション → リポジトリ → スキーマ → サービス → API →
   単体テスト → 統合テスト → 契約テスト → ドキュメント更新
4. 各タスクは `- [ ] タスク内容 (対応: FR-00X)` の形式のチェックボックスにする。
5. 完了したらタスク数と概要を報告する。まだ実装には着手しない。
